# Resy Snipe Bot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a web dashboard + async backend that sniping Resy reservations at their exact opening time, books automatically, and notifies via SMS.

**Architecture:** Python/FastAPI backend with APScheduler for timing-critical snipe jobs; React frontend served as static files via Nginx on EC2 t3.nano; SQLite for persistence; EventBridge auto-starts the instance before each snipe and the bot stops it after.

**Tech Stack:** Python 3.12, FastAPI, httpx (async), APScheduler, aiosqlite, Twilio, boto3, React 18, Vite, Tailwind CSS, Nginx, systemd, EC2 t3.nano (us-east-1)

import json
import aiosqlite
from datetime import datetime, timezone
from typing import Optional

class Database:
    def __init__(self, path: str):
        self.path = path
        self._db: Optional[aiosqlite.Connection] = None

    async def init(self):
        self._db = await aiosqlite.connect(self.path)
        self._db.row_factory = aiosqlite.Row
        await self._db.execute("PRAGMA journal_mode=WAL")
        await self._create_tables()

    async def close(self):
        if self._db:
            await self._db.close()

    async def _create_tables(self):
        await self._db.execute("""
            CREATE TABLE IF NOT EXISTS targets (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                venue_id TEXT NOT NULL,
                venue_name TEXT NOT NULL,
                date TEXT NOT NULL,
                party_size INTEGER NOT NULL,
                opening_time TEXT NOT NULL,
                preferred_start TEXT,
                preferred_end TEXT,
                status TEXT NOT NULL DEFAULT 'pending',
                booked_at TEXT,
                reservation_details TEXT
            )
        """)
        await self._db.execute("""
            CREATE TABLE IF NOT EXISTS config (
                key TEXT PRIMARY KEY,
                value TEXT
            )
        """)
        await self._db.commit()

    async def execute_fetchall(self, sql: str, params=()) -> list[dict]:
        async with self._db.execute(sql, params) as cursor:
            rows = await cursor.fetchall()
            return [dict(r) for r in rows]

    async def insert_target(self, t: dict) -> int:
        async with self._db.execute(
            """INSERT INTO targets
               (venue_id, venue_name, date, party_size, opening_time,
                preferred_start, preferred_end, status)
               VALUES (?, ?, ?, ?, ?, ?, ?, 'pending')""",
            (t["venue_id"], t["venue_name"], t["date"], t["party_size"],
             t["opening_time"], t.get("preferred_start"), t.get("preferred_end"))
        ) as cursor:
            await self._db.commit()
            return cursor.lastrowid

    async def get_all_targets(self) -> list[dict]:
        return await self.execute_fetchall(
            "SELECT * FROM targets ORDER BY opening_time"
        )

    async def get_pending_targets(self) -> list[dict]:
        return await self.execute_fetchall(
            "SELECT * FROM targets WHERE status = 'pending' ORDER BY opening_time"
        )

    async def get_target(self, target_id: int) -> Optional[dict]:
        rows = await self.execute_fetchall(
            "SELECT * FROM targets WHERE id = ?", (target_id,)
        )
        return rows[0] if rows else None

    async def update_target_status(self, target_id: int, status: str):
        await self._db.execute(
            "UPDATE targets SET status = ? WHERE id = ?", (status, target_id)
        )
        await self._db.commit()

    async def update_target_booked(self, target_id: int, reservation_details: dict):
        now = datetime.now(timezone.utc).isoformat()
        await self._db.execute(
            """UPDATE targets
               SET status = 'booked', booked_at = ?, reservation_details = ?
               WHERE id = ?""",
            (now, json.dumps(reservation_details), target_id)
        )
        await self._db.commit()

    async def delete_target_if_pending(self, target_id: int) -> bool:
        async with self._db.execute(
            "DELETE FROM targets WHERE id = ? AND status = 'pending'", (target_id,)
        ) as cursor:
            await self._db.commit()
            return cursor.rowcount > 0

    async def set_config(self, key: str, value: str):
        await self._db.execute(
            "INSERT OR REPLACE INTO config (key, value) VALUES (?, ?)", (key, value)
        )
        await self._db.commit()

    async def get_config(self, key: str) -> Optional[str]:
        rows = await self.execute_fetchall(
            "SELECT value FROM config WHERE key = ?", (key,)
        )
        return rows[0]["value"] if rows else None

    async def get_all_config(self) -> dict[str, str]:
        rows = await self.execute_fetchall("SELECT key, value FROM config")
        return {r["key"]: r["value"] for r in rows}
```

from dataclasses import dataclass, fields
from database import Database

CONFIG_KEYS = [
    "resy_api_key", "resy_auth_token",
    "twilio_account_sid", "twilio_auth_token", "twilio_from",
    "phone_number",
]

@dataclass
class Settings:
    resy_api_key: str = ""
    resy_auth_token: str = ""
    twilio_account_sid: str = ""
    twilio_auth_token: str = ""
    twilio_from: str = ""
    phone_number: str = ""

async def load_settings(db: Database) -> Settings:
    raw = await db.get_all_config()
    return Settings(**{k: raw.get(k, "") for k in CONFIG_KEYS})

async def save_settings(db: Database, settings: Settings):
    for f in fields(settings):
        await db.set_config(f.name, getattr(settings, f.name) or "")
```

`backend/resy.py`:
```python
import httpx
from typing import Optional

class ResyClient:
    BASE_URL = "https://api.resy.com"

    def __init__(self, api_key: str, auth_token: str):
        self.api_key = api_key
        self.auth_token = auth_token
        self._client: Optional[httpx.AsyncClient] = None

    def _auth_header(self) -> str:
        return f'ResyKey apikey="{self.api_key}",auth_token="{self.auth_token}"'

    async def connect(self):
        self._client = httpx.AsyncClient(
            base_url=self.BASE_URL,
            headers={
                "Authorization": self._auth_header(),
                "Content-Type": "application/json",
                "User-Agent": "Mozilla/5.0",
            },
            timeout=10.0,
        )
        # Pre-warm the connection
        await self._client.get("/4/find", params={
            "lat": 0, "long": 0, "day": "2000-01-01", "party_size": 1
        })

    async def close(self):
        if self._client:
            await self._client.aclose()
            self._client = None

    async def find_slots(self, venue_id: str, date: str, party_size: int) -> list[dict]:
        resp = await self._client.get("/4/find", params={
            "lat": 0,
            "long": 0,
            "day": date,
            "party_size": party_size,
            "venue_id": venue_id,
        })
        resp.raise_for_status()
        venues = resp.json().get("results", {}).get("venues", [])
        if not venues:
            return []
        return venues[0].get("slots", [])

    async def get_book_token(self, config_id: str, date: str, party_size: int) -> str:
        resp = await self._client.post("/3/details", json={
            "commit": 1,
            "config_id": config_id,
            "day": date,
            "party_size": party_size,
        })
        resp.raise_for_status()
        return resp.json()["book_token"]["value"]

    async def book(self, book_token: str) -> dict:
        resp = await self._client.post("/3/book", json={
            "book_token": book_token,
            "struct_payment_method": '{"id": 0}',
            "source_id": "resy.com-venue-details",
        })

import logging
import boto3
from botocore.exceptions import ClientError

logger = logging.getLogger(__name__)

class AWSClient:
    def __init__(self, region: str, instance_id: str):
        self.region = region
        self.instance_id = instance_id
        self._events = boto3.client("events", region_name=region)
        self._ec2 = boto3.client("ec2", region_name=region)

    @staticmethod
    def get_instance_id() -> str:
        """Fetch instance ID from EC2 metadata service. Returns empty string outside EC2."""
        import urllib.request
        try:
            # IMDSv2
            token_req = urllib.request.Request(
                "http://169.254.169.254/latest/api/token",
                method="PUT",
                headers={"X-aws-ec2-metadata-token-ttl-seconds": "21600"},
            )
            with urllib.request.urlopen(token_req, timeout=1) as r:
                token = r.read().decode()
            req = urllib.request.Request(
                "http://169.254.169.254/latest/meta-data/instance-id",
                headers={"X-aws-ec2-metadata-token": token},
            )
            with urllib.request.urlopen(req, timeout=1) as r:
                return r.read().decode()
        except Exception:
            return ""

    def create_start_rule(self, rule_name: str, cron_expression: str, instance_id: str):
        """Create an EventBridge rule that starts the EC2 instance on a schedule."""
        ec2_arn = f"arn:aws:ec2:{self.region}::instance/{instance_id}"
        self._events.put_rule(
            Name=rule_name,
            ScheduleExpression=cron_expression,
            State="ENABLED",
            Description=f"Resy bot auto-start for {rule_name}",
        )
        # EventBridge needs an IAM role ARN to start EC2; use the instance's attached role
        # The actual role ARN must be configured as an env var (EVENTBRIDGE_ROLE_ARN)
        import os
        role_arn = os.environ.get("EVENTBRIDGE_ROLE_ARN", "")
        if not role_arn:
            logger.warning("EVENTBRIDGE_ROLE_ARN not set — EventBridge target not attached")
            return
        self._events.put_targets(
            Rule=rule_name,
            Targets=[{
                "Id": "start-ec2",
                "Arn": f"arn:aws:ssm:{self.region}::automation-definition/AWS-StartEC2Instance",
                "RoleArn": role_arn,
                "Input": f'{{"InstanceId": ["{instance_id}"]}}',
            }],
        )

    def delete_rule(self, rule_name: str):
        """Remove targets then delete the EventBridge rule."""
        try:
            self._events.remove_targets(Rule=rule_name, Ids=["start-ec2"])
        except ClientError as e:
            if e.response["Error"]["Code"] not in ("ResourceNotFoundException", "ValidationException"):
                logger.error(f"Failed to remove targets for rule {rule_name}: {e}")
        try:
            self._events.delete_rule(Name=rule_name)
        except ClientError as e:
            if e.response["Error"]["Code"] != "ResourceNotFoundException":
                logger.error(f"Failed to delete rule {rule_name}: {e}")

    def stop_self(self):
        """Stop this EC2 instance."""
        if not self.instance_id:
            logger.warning("No instance ID — cannot stop self")
            return
        try:
            self._ec2.stop_instances(InstanceIds=[self.instance_id])
            logger.info(f"Stopping instance {self.instance_id}")
        except Exception as e:
            logger.error(f"Failed to stop instance: {e}")

import asyncio
import logging
from datetime import datetime

logger = logging.getLogger(__name__)

# Configurable for testing
PHASE1_DURATION = 60.0   # seconds — poll every 1s
PHASE2_DURATION = 60.0   # seconds — poll every 2s
PHASE1_INTERVAL = 1.0
PHASE2_INTERVAL = 2.0

def filter_slots(slots: list[dict], preferred_start: str | None, preferred_end: str | None) -> list[dict]:
    if not preferred_start and not preferred_end:
        return slots
    result = []
    for slot in slots:
        slot_time_str = slot["date"]["start"].split(" ")[1][:5]  # "HH:MM"
        if preferred_start and slot_time_str < preferred_start:
            continue
        if preferred_end and slot_time_str > preferred_end:
            continue
        result.append(slot)
    return result

async def _book_with_retry(resy_client, book_token: str) -> dict:
    """Retry booking with the same book_token on timeout. Raises on terminal errors."""
    while True:
        try:
            return await resy_client.book(book_token)
        except Exception as e:
            import httpx
            if isinstance(e, httpx.TimeoutException):
                logger.warning("Book request timed out — retrying with same token")
                continue
            raise

async def run_snipe(target: dict, resy_client, sms_client, db) -> None:
    target_id = target["id"]
    venue_name = target["venue_name"]
    venue_id = target["venue_id"]
    date = target["date"]
    party_size = target["party_size"]
    preferred_start = target.get("preferred_start")
    preferred_end = target.get("preferred_end")

    await db.update_target_status(target_id, "sniping")
    logger.info(f"[{venue_name}] Snipe started")

    booking_in_flight = False
    booked = False

    async def attempt_booking(slot: dict):
        nonlocal booking_in_flight, booked
        if booking_in_flight or booked:
            return
        booking_in_flight = True
        try:
            config_id = slot["config"]["token"]
            book_token = await resy_client.get_book_token(config_id, date, party_size)
            result = await _book_with_retry(resy_client, book_token)
            booked = True
            await db.update_target_booked(target_id, result)
            sms_client.send(f"Booked {venue_name} on {date} for {party_size}!")
            logger.info(f"[{venue_name}] Booked successfully")
        except Exception as e:
            logger.error(f"[{venue_name}] Booking failed: {e}")
            await db.update_target_status(target_id, "failed")
            sms_client.send(f"Failed to book {venue_name} on {date}: {e}")
        finally:
            if not booked:
                booking_in_flight = False

    loop = asyncio.get_event_loop()

    async def poll(interval: float, duration: float):
        deadline = loop.time() + duration
        while loop.time() < deadline and not booked:
            try:
                slots = await resy_client.find_slots(venue_id, date, party_size)
                matching = filter_slots(slots, preferred_start, preferred_end)
                if matching and not booking_in_flight and not booked:
                    asyncio.ensure_future(attempt_booking(matching[0]))
            except Exception as e:
                logger.warning(f"[{venue_name}] find_slots error: {e}")
            await asyncio.sleep(interval)

    await poll(PHASE1_INTERVAL, PHASE1_DURATION)
    if not booked:
        await poll(PHASE2_INTERVAL, PHASE2_DURATION)

    if not booked and not booking_in_flight:
        await db.update_target_status(target_id, "failed")
        sms_client.send(f"Failed to book {venue_name} on {date} — no slots found in 2 minute window")
        logger.warning(f"[{venue_name}] Snipe window expired with no booking")
```

import asyncio
import logging
import os
from datetime import datetime, timezone, timedelta
from apscheduler.schedulers.asyncio import AsyncIOScheduler
from snipe import run_snipe

logger = logging.getLogger(__name__)

def _eventbridge_rule_name(target_id: int) -> str:
    return f"resy-bot-target-{target_id}"

def _opening_time_to_cron(opening_time: datetime) -> str:
    """Convert a UTC datetime to an EventBridge cron expression (UTC)."""
    t = opening_time.astimezone(timezone.utc) - timedelta(minutes=10)
    return f"cron({t.minute} {t.hour} {t.day} {t.month} ? {t.year})"

class SnipeScheduler:
    def __init__(self, db, resy_client, sms_client, aws_client):
        self.db = db
        self.resy_client = resy_client
        self.sms_client = sms_client
        self.aws_client = aws_client
        self._scheduler = AsyncIOScheduler(timezone="UTC")
        self._active_jobs: set[int] = set()

    def start(self):
        self._scheduler.start()

    def shutdown(self):
        self._scheduler.shutdown(wait=False)

    def has_job(self, target_id: int) -> bool:
        return self._scheduler.get_job(str(target_id)) is not None

    def schedule_target(self, target: dict):
        target_id = target["id"]
        opening_time = datetime.fromisoformat(target["opening_time"])
        if opening_time.tzinfo is None:
            opening_time = opening_time.replace(tzinfo=timezone.utc)

        if opening_time <= datetime.now(timezone.utc):
            logger.warning(f"Target {target_id} opening_time is in the past — skipping")
            return

        # Schedule the pre-warm 5 minutes before
        prewarm_time = opening_time - timedelta(minutes=5)

        self._scheduler.add_job(
            self._run_prewarm_and_snipe,
            "date",
            run_date=prewarm_time,
            id=str(target_id),
            args=[target],
        )
        logger.info(f"Scheduled snipe for target {target_id} at {opening_time.isoformat()}")

    def cancel_target(self, target_id: int):
        job = self._scheduler.get_job(str(target_id))
        if job:
            job.remove()
            logger.info(f"Cancelled snipe job for target {target_id}")

    async def _run_prewarm_and_snipe(self, target: dict):
        target_id = target["id"]
        opening_time = datetime.fromisoformat(target["opening_time"])
        if opening_time.tzinfo is None:
            opening_time = opening_time.replace(tzinfo=timezone.utc)

        self._active_jobs.add(target_id)
        try:
            # Pre-warm connection
            logger.info(f"[{target['venue_name']}] Pre-warming connection")
            await self.resy_client.connect()

            # Wait until opening time
            now = datetime.now(timezone.utc)
            wait_seconds = (opening_time - now).total_seconds()
            if wait_seconds > 0:
                await asyncio.sleep(wait_seconds)

            await run_snipe(target, self.resy_client, self.sms_client, self.db)
        finally:
            await self.resy_client.close()
            self._active_jobs.discard(target_id)
            if not self._active_jobs and os.environ.get("AUTO_STOP") == "true":
                logger.info("All jobs complete — stopping instance")
                self.aws_client.stop_self()

    async def reload_pending(self):
        """On startup, reschedule all pending targets from the database."""
        targets = await self.db.get_pending_targets()
        for target in targets:
            self.schedule_target(target)
        logger.info(f"Reloaded {len(targets)} pending targets from database")
```

    db = request.app.state.db
    scheduler = request.app.state.scheduler
    aws = request.app.state.aws_client
    target_data = body.model_dump()
    target_id = await db.insert_target(target_data)
    target = await db.get_target(target_id)
    # Create EventBridge rule to start instance 10 min before opening
    rule_name = f"resy-bot-target-{target_id}"
    from datetime import datetime, timezone, timedelta
    opening_time = datetime.fromisoformat(body.opening_time)
    if opening_time.tzinfo is None:
        opening_time = opening_time.replace(tzinfo=timezone.utc)
    prewarm_cron = _to_cron(opening_time - timedelta(minutes=10))
    try:

    except Exception as e:

        logging.getLogger(__name__).warning(f"EventBridge rule creation failed: {e}")
    scheduler.schedule_target(target)
    return target

    db = request.app.state.db
    scheduler = request.app.state.scheduler
    aws = request.app.state.aws_client
    deleted = await db.delete_target_if_pending(target_id)
    if not deleted:

    from datetime import timezone

    return f"cron({t.minute} {t.hour} {t.day} {t.month} ? {t.year})"

def create_app(db=None, scheduler=None, aws_client=None) -> FastAPI:
    @asynccontextmanager
    async def lifespan(app: FastAPI):
        # Init DB
        _db = db or Database(os.environ.get("DATABASE_PATH", "resy.db"))
        if not db:
            await _db.init()
        app.state.db = _db

        # Init clients
        cfg = await load_settings(_db)
        resy_client = ResyClient(cfg.resy_api_key, cfg.resy_auth_token)
        sms_client = SMSClient(
            cfg.twilio_account_sid, cfg.twilio_auth_token,
            cfg.twilio_from, cfg.phone_number,
        )
        instance_id = AWSClient.get_instance_id()
        _aws = aws_client or AWSClient(region="us-east-1", instance_id=instance_id)
        _aws.instance_id = instance_id
        app.state.aws_client = _aws

        # Init scheduler
        _scheduler = scheduler or SnipeScheduler(
            db=_db, resy_client=resy_client,
            sms_client=sms_client, aws_client=_aws,
        )
        if not scheduler:
            _scheduler.start()
            await _scheduler.reload_pending()
        app.state.scheduler = _scheduler

        yield

        if not scheduler:
            _scheduler.shutdown()
        if not db:
            await _db.close()

    app = FastAPI(title="Resy Bot", lifespan=lifespan)
    app.include_router(targets.router)
    app.include_router(settings_router.router)

    @app.get("/api/health")
    async def health():
        return {"status": "ok"}

    # Serve React build in production
    frontend_dist = os.path.join(os.path.dirname(__file__), "..", "frontend", "dist")
    if os.path.isdir(frontend_dist):
        app.mount("/", StaticFiles(directory=frontend_dist, html=True), name="static")

    return app

app = create_app()

async function request<T>(method: string, path: string, body?: unknown): Promise<T> {
  const resp = await fetch(`${BASE}${path}`, {

    body: body !== undefined ? JSON.stringify(body) : undefined,

  const [saved, setSaved] = useState(false);
  const [error, setError] = useState("");

  useEffect(() => {
    api.settings.get().then(setForm).catch(() => setError("Failed to load settings"));
  }, []);

  async function handleSubmit(e: React.FormEvent) {
    e.preventDefault();
    setSaving(true); setError(""); setSaved(false);
    try {
      await api.settings.update(form);
      setSaved(true);
    } catch {
      setError("Failed to save settings");
    } finally {
      setSaving(false);
    }
  }

  const field = (label: string, key: keyof AppSettings, type = "text") => (
    <div className="flex flex-col gap-1">
      <label className="text-sm font-medium text-gray-700">{label}</label>
      <input type={type} className="border rounded px-3 py-1.5 text-sm font-mono"
        value={form[key]} onChange={e => setForm(f => ({ ...f, [key]: e.target.value }))} />
    </div>
  );

  return (
    <div className="max-w-xl mx-auto p-6">
      <h1 className="text-2xl font-bold mb-6">Settings</h1>
      {error && <p className="text-red-600 text-sm mb-4">{error}</p>}
      {saved && <p className="text-green-600 text-sm mb-4">Settings saved.</p>}
      <form onSubmit={handleSubmit} className="bg-white border rounded-lg p-5 space-y-4 shadow-sm">
        <h2 className="font-semibold text-gray-800">Resy Credentials</h2>
        <p className="text-xs text-gray-500">Find these in your browser's Network tab when browsing Resy.</p>
        {field("API Key", "resy_api_key")}
        {field("Auth Token", "resy_auth_token")}
        <h2 className="font-semibold text-gray-800 pt-2">Twilio (SMS)</h2>
        {field("Account SID", "twilio_account_sid")}
        {field("Auth Token", "twilio_auth_token")}
        {field("From Number", "twilio_from", "tel")}
        {field("Your Phone Number", "phone_number", "tel")}
        <button type="submit" disabled={saving}
          className="bg-indigo-600 text-white px-5 py-2 rounded text-sm font-medium hover:bg-indigo-700 disabled:opacity-50">
          {saving ? "Saving…" : "Save Settings"}
        </button>
      </form>
    </div>
  );
}
```

## Task 15: IAM Setup (manual steps, documented)

> These steps are performed once in the AWS Console. No code.

- [ ] **Step 1: Create EC2 IAM role**

In AWS Console → IAM → Roles → Create Role:
- Trusted entity: EC2
- Name: `ResyBotEC2Role`
- Attach inline policy:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["events:PutRule", "events:PutTargets", "events:DeleteRule", "events:RemoveTargets", "events:ListRules"],
      "Resource": "*"
    },
    {
      "Effect": "Allow",
      "Action": ["ec2:StopInstances"],
      "Resource": "*"
    }
  ]
}
```

- [ ] **Step 2: Create EventBridge IAM role**

In AWS Console → IAM → Roles → Create Role:
- Trusted entity: EventBridge (events.amazonaws.com)
- Name: `ResyBotEventBridgeRole`
- Attach inline policy:

```json
{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Action": "ssm:StartAutomationExecution",
    "Resource": "arn:aws:ssm:*::automation-definition/AWS-StartEC2Instance"
  }]
}
```

- [ ] **Step 3: Attach role to EC2 instance**

EC2 Console → Select instance → Actions → Security → Modify IAM Role → Select `ResyBotEC2Role`

- [ ] **Step 4: Add EventBridge role ARN to .env**

SSH into instance:
```bash
# Get the role ARN from IAM Console → ResyBotEventBridgeRole → copy ARN
echo "EVENTBRIDGE_ROLE_ARN=arn:aws:iam::123456789:role/ResyBotEventBridgeRole" >> /opt/resy-bot/.env
```
